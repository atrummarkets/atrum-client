Fresh-note proof — testing the seam that was never tested

Every proof this project has produced so far, in the harness and in atrum-core, used inputs the repo generated for itself. This one starts from a note created here, in the browser, from fresh randomness — then builds the witness, proves it, and checks it against the circuit’s own verification key. If the client’s idea of a commitment disagrees with note.circom by one bit, this fails.
